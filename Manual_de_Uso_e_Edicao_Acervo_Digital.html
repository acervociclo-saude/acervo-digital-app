1. Princípio Central do Produto

O Acervo Digital Ciclo Saúde Proteção Social não é um novo repositório de arquivos. Ele foi construído como uma camada de experiência, navegação e arquitetura da informação sobre o repositório existente no Google Drive.

O objetivo é eliminar o esforço cognitivo do usuário (gestores, profissionais de saúde e articuladores municipais). Ele não precisa saber onde os arquivos estão guardados nem como as pastas estão organizadas. Ele apenas reconhece seu contexto e faz escolhas simples:

👉 Maranhão ➔ Temas (1 a 3 opções) ➔ Tópico Específico ➔ Pasta Aberta no Google Drive.

2. Como Funciona a Navegação (As 9 Telas)

A aplicação foi desenvolvida em formato mobile-first (proporção 9:16), funcionando com perfeição tanto no celular quanto no computador:

Tela Nome da Tela Comportamento e Regras
Tela 1 Início / Dropdown Fechado Apresentação com botão para selecionar o estado.
Tela 2 Seleção de Estado Apenas Maranhão (MA) ativo. Clicar em outros estados exibe o alerta: "Atualmente apenas os arquivos do Maranhão estão disponíveis."
Tela 3 Transição Automática Feedback visual rápido (200ms) destacando a opção Maranhão em amarelo.
Tela 4 Estado Confirmado Exibe Maranhão selecionado e o botão "CONTINUAR >".
Tela 5 Seleção de Temas (1 a 3) Permite marcar entre 1 e 3 temas. Cada clique apenas seleciona/desmarca (toggle). Limite rigoroso de 3 temas. Validação determinística no botão CONTINUAR.
Tela 6 Acervo de Conteúdos Lista vertical dos 13 temas/tópicos de saúde disponíveis para a rota.
Tela 7 Feedback do Tópico Transição automática de 200ms destacando em amarelo o tópico escolhido.
Tela 8 Launcher de Destino Botão "Clique aqui" (abre a pasta no Google Drive em nova aba), link "<< Voltar pra seleção" e botão "CONTINUAR >".
Tela 9 Conclusão / Reinício Tela de encerramento com botão para reiniciar o fluxo a partir da Tela 1.

3. Regras de Validação dos Temas (Tela 5)

  • Mínimo 1 e Máximo 3 temas: O usuário pode selecionar 1, 2 ou 3 temas simultaneamente.
  • Comportamento Toggle: Cada clique em um tema alterna seu estado entre marcado e desmarcado, sem navegar sozinho.
  • Tentativa do 4º tema: Se já houver 3 temas marcados e o usuário clicar no 4º, o sistema não adiciona e exibe: "Selecione entre 1 e 3 opções".
  • Validação no CONTINUAR: Ao clicar em CONTINUAR com 0 temas: avisa "Selecione entre 1 e 3 opções".
  • Rota Inexistente no CSV: Se a combinação não tiver pasta cadastrada: avisa "A combinação selecionada não possui rota disponível."
  • Independência de Ordem: A ordem dos cliques não afeta o resultado (Saúde + SUS é idêntico a SUS + Saúde).

4. Guia Prático de Edição de Conteúdos

📍 Como alterar ou atualizar Links do Google Drive

Arquivo: src/data/ma_saude_sus.json

Abra o arquivo no editor de texto. Cada um dos 13 tópicos possui o número, nome e o link correspondente. Para alterar para uma nova pasta, basta colar a nova URL no campo linkDrive:

{
  "numero": "01",
  "tema": "Saúde da Mulher",
  "linkDrive": "https://drive.google.com/drive/folders/COLE_O_NOVO_LINK_AQUI"
}

📍 Como adicionar ou alterar Rotas de Temas

Arquivo: src/data/rotas.json

As rotas conectam os temas da Tela 5 ao arquivo de conteúdos da Tela 6. Para cadastrar uma nova combinação, adicione uma nova entrada:

{
  "estado": "MA",
  "themes": ["Saúde", "SUS"],
  "routeCode": "MA_SAUDE_SUS",
  "destinationSheet": "MA_SAUDE_SUS"
}

📍 Como atualizar as Imagens das Telas

Pasta: public/assets/

Basta colar as novas imagens em formato PNG de alta resolução (3375 x 6000 px), substituindo os arquivos com os mesmos nomes (tela-1.png até tela-9.png).

5. Como Testar e Publicar Atualizações

1. Testar localmente no computador:

npm run dev

Abra http://localhost:5173/ no navegador. O Vite atualiza a tela na hora!

2. Rodar os testes automatizados:

npm test

Verifica os 26 testes de validação para garantir que nada foi quebrado.

3. Salvar no GitHub da equipe:

git add .
git commit -m "Atualização de links"
git push

4. Publicar a versão atualizada no ar (Vercel):

npx vercel --prod

O site oficial https://acervo-digital-app.vercel.app é atualizado imediatamente!

6. Cuidados Importantes de Segurança

  • Não é necessária nenhuma API de segurança: O aplicativo não armazena senhas, CPFs nem dados confidenciais.
  • Criptografia HTTPS: A Vercel fornece certificado SSL/HTTPS e proteção de servidores automaticamente.
  • Permissão no Google Drive: As pastas e arquivos compartilhados no Google Drive devem ser SEMPRE mantidos como "Leitor" / "Visualizador", nunca como "Editor", para impedir que terceiros apaguem ou editem documentos acidentalmente.
